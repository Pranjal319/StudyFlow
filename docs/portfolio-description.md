# Portfolio Description

## Short Version

StudyFlow is a full stack web application that generates personalized study schedules using AI-inspired planning logic. Students can add subjects, define deadlines, track progress, use a Pomodoro timer, and review analytics through a modern dashboard.

## Detailed Version

StudyFlow is a portfolio-ready full stack application built with Next.js, Express.js, MongoDB, and JWT authentication. The app helps students organize their study workload by turning subject priorities, exam deadlines, and available study hours into a balanced daily schedule. It also includes task management, progress tracking, reminders, analytics dashboards, weak-subject recommendations, dark mode, and a printable study plan view.

## Resume Bullet Ideas

- Built a full stack study planning platform using Next.js, Express.js, MongoDB, and JWT authentication.
- Designed an AI-inspired scheduling engine that allocates daily study blocks using deadlines, priorities, and available hours.
- Implemented analytics dashboards, Pomodoro workflow support, task tracking, and gamified streak features.
